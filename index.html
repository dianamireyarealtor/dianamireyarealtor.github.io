Creative Studio

Creative Studio is a private video-production application used only by Diana Mireya Realtor and her team to edit short marketing videos from their own footage. It is not offered to the public, and there is no sign-up.

How it uses Google Drive

Creative Studio saves the owner's original video footage to the owner's own Google Drive, so the footage is protected even if a device is lost. It requests Google's drive.file permission, which Google describes as access to "only the specific Google Drive files you use with this app". Creative Studio works only in the Drive folder the owner selects when connecting Drive and with the files and folders it creates there.

After each upload, Creative Studio compares the checksum Google reports for the stored file with the original, to confirm the copy in Drive is complete and unchanged.
